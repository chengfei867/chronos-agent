Triage decision: **bug-fix-first commit ordering** (per `cron-slot-handoff-recovery` skill rule 10 + `dogfood` skill bug ordering). Rather than mass-rewrite or revert, ran the test suite to find the failure surface and fix the root cause.

**Root cause found**: `tests/unit/test_cli_eval.py::_seed` sorted seeded runs by `r.created_at` to disambiguate parent vs. child after `SqliteStore.list_runs()`. The Pydantic `Run` model exposes `started_at` / `ended_at` only — never `created_at`. The lambda raised `AttributeError`, which short-circuited 8 of the 13 eval CLI tests.

**Fix**: One-line patch to sort by `started_at` instead. Verified via `pytest tests/unit/test_cli_eval.py` (13 GREEN), then full suite (745 GREEN). Spike21 was already passing — the bug was confined to the test helper. The skill rule 10 reference holds: this is the R115 WIP it warned about.
