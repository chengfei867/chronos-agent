## Decisions

- **Registry safety net** — `try { formatter(node) } catch { return formatDefault(node); console.warn }`.
  Per-adapter formatters can be incrementally added/changed without risking
  a Replay page crash for users whose runs use the affected adapter.
  Trade-off: silent fallback on bug → mitigated by `console.warn`.
- **No anthropic_agents block-content rendering** (text body, tool input
  JSON, tool result content) is specially formatted yet — every block is
  rendered as its full `safeStringify`'d JSON dict in the section's `<pre>`.
  Rationale: slice 2 scope is "structured sections, not raw blob"; deeper
  formatting (e.g. rendering text blocks as plain text, tool_use as a
  param table) is a candidate for slice 3 or a follow-up.
- **Other adapters stay on default** — autogen, crewai, openai_agents
  keep the raw JSON dump (just routed through `formatDefault` so the
  framing is consistent). They're R94+ candidates if their state shapes
  diverge enough to warrant per-adapter UI.
- **Top 5 anthropic blocks open by default** — heuristic to keep the
  panel compact when a long conversation has many `TextBlock`s. Users can
  expand the rest via `<Collapse>` headers; full raw view always available
  via the toggle.
