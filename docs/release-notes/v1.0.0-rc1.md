# chronos-agent v1.0.0-rc1 — 2026-06-08

> **Release Candidate 1** — final acceptance testing window. If no P0 surfaces during R121–R122 dogfood, this RC promotes to **v1.0.0 GA**.

`pdb + git` for multi-agent AI reasoning trees. Record once, replay deterministically, fork from any node, diff branch outcomes, track tokens/cost, score with evaluators.

## Highlights

- **Five working agent adapters** — LangGraph, Anthropic Agents SDK (`claude-agent-sdk`), CrewAI, AutoGen, plus Linear pipeline. Adapter zero-regression streak: R52 → R120 = **68 rounds** (`src/chronos/adapters/` byte-untouched across the entire Phase 6 polish track).
- **Cost visibility (ADR-029)** — `chronos runs list` shows token + cost columns by default; frontend `RunList` mirrors them; quickstart demo populates `usage` so the column reads non-zero on first try.
- **Evaluator framework (ADR-030)** — `chronos eval run --evaluator <name>` produces a numeric score per run; `chronos eval list` enumerates results; `chronos compare --eval` ranks two runs by score; frontend Score column. Two built-in evaluators ship: `output_length_chars` and `final_state_key_present`.
- **One-command quickstart** — `chronos quickstart --demo langgraph-router` (or `crewai-research-team` / `anthropic-agent-tools` / `builtin-minimal`) loads a pre-recorded run + fork into a fresh DB; `--list` enumerates available demos with recommended evaluators.
- **`chronos doctor`** — environment / DB / schema / extras health check. 6 ✅ on a clean install, ⚠️ rows for missing optional extras with actionable hints.
- **mkdocs-material docs site** — getting-started, cli-reference, concepts, evaluators, cost-tracking, FAQ. Auto-deployed to GitHub Pages on every push to `main`.
- **Bilingual README** — `README.md` (English) + `README.zh-CN.md` (中文). Identical structure, separate prose.
- **Onboarding tour** — landing page surface walks new users through the five core flows. Skippable + replayable.
- **769 passed / 9 skipped / 0 failed** local pytest baseline; CI now matches local after the R120 `--all-extras` fix.

## Quickstart (5 minutes)

```bash
# 1. Install (dev install with all extras)
git clone https://github.com/chengfei867/chronos-agent.git
cd chronos-agent
uv sync --all-extras

# 2. Load a demo
uv run chronos quickstart --demo langgraph-router

# 3. List runs (Tokens + Cost ¢ visible by default)
uv run chronos runs list

# 4. Score the run
uv run chronos eval run --run <run_id> --evaluator output_length_chars

# 5. Compare parent vs fork by score
uv run chronos compare <parent_id> <fork_id> --eval output_length_chars

# 6. Open the web UI
uv run chronos web
# → http://localhost:8000
```

`uv run chronos quickstart --list` enumerates all available demos.
`uv run chronos doctor` reports env/DB/schema/extras health if anything looks off.
