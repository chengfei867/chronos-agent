    Backend (1 file)¶

    • src/chronos/cli/web.py (+50 LOC, including 30-LOC helper + ~10 LOC wire-in)
    • New _pid_file_path(host, port) -> Path: $XDG_RUNTIME_DIR/chronos-web-<host>-<port>.pid (Linux runtime-state convention) with /tmp fallback. Per-(host,port) filename so two parallel instances on different ports don't trample each other.
    • New _reap_stale_pid_file(pid_file, console): os.kill(old_pid, 0) to probe; ProcessLookupError → reap with a [yellow]note:[/] message; PermissionError (alive but other-user) → leave alone; corrupt file (non-int) → silently nuke. Best-effort throughout (read-only filesystem etc. don't break serving).
    • Wire-in to web_command: reap-then-write before banner; cleanup in finally next to store.close(). Both wrapped in contextlib.suppress(OSError) — never block serving on PID-file plumbing.
