## 决策 (D-117-x)

- **D-117-1: i18n 推到 R118+, R117 文档站英文 only.** R116 README 已双语 (满足 R122 必过项 \"README 中英双语\" 字面要求). mkdocs-static-i18n + 6 新页 + i18n nav 翻倍同 slot 实现风险高. R117 站点英文上线锁 R122 必过项 \"文档站 6 节\" 行, 中文化 R118 (examples arc) 顺手 / 否则 v1.1+ post-1.0.
- **D-117-2: deferred items 只 ship #3.** 见上表 \"为什么先做 #3\".
- **D-117-3: GitHub Pages 设置不开.** R117 plan 硬约束之一. workflow push 到 gh-pages 分支建好 artifact, repo Settings → Pages 留给用户 R120 拍板 public 时一键开. R117 commit 推到 main 后 GHA 会自动跑一次 build + push, 验证 workflow 本身正确.
- **D-117-4: `mkdocs.yml` 用 `astral-sh/setup-uv@v5` 装依赖, 不用 pip.** 与项目 ci.yml 工具链一致 (uv 是项目 canonical), CI cache 也复用. workflow 内一行 `uv pip install --system` 取代 pip + venv 链路.
- **D-117-5: ADR 索引页 (`docs/decisions/index.md`) 一行一 ADR + 状态.** mkdocs `--strict` 不允许 nav 指向不存在的文件; ADR 目录有 30+ 个文件, 不能每个都进 top-level nav. 索引页内列全部 ADR, nav 只挂这一个入口. 状态列方便用户找当前 effective ADR (Superseded 那些避免 misread).
