## 4. Decisions

### D-99-1 — Promote Arc D from hot-backup to second-arc primary

ADR-027 §6 had pre-authorised Arc D as a fallback if R91 spike 16 failed. The fallback
never triggered (Arc C shipped clean). R99 promotes Arc D to second-arc primary not as
a fallback but as the next-most-valuable arc on its own merits per the r90 ranking.

Rationale:
- Phase 5 was always implicitly two-arc (Arc C primary, Arc D pre-authorised). With
  Arc C shipped, Arc D is the natural next step.
- Test-infrastructure ROI peaks now: 4 first-class adapters live, 46-round
  zero-regression streak gives clean ground-truth for golden capture.
- No competing arc has surfaced. Arc E (5th adapter) needs external user demand. Arc F
  (recorder per-block split) is locked behind R85→R89 Option (a) decision.
- Foundation work before any new user-facing surface (cloud, team features, pricing)
  per Phase 5 roadmap-order discipline.

### D-99-2 — Tooling shape: dedicated `chronos verify-golden` CLI verb (over pytest plugin)

ADR-028 §3 trade-off:

| Aspect                    | CLI verb              | pytest plugin       |
|---------------------------|-----------------------|---------------------|
| Isolation from unit tests | ✅ separate process   | ❌ shares fixtures  |
| Discovery side effects    | ✅ none               | ❌ collection order |
| `--record` mode           | ✅ trivial            | ❌ awkward          |
| CI integration            | ✅ separate job       | ✅ same job         |
| Local dev ergonomics      | ✅ explicit verb      | ⚠️ implicit         |

CLI wins on 4 of 5. Pytest matrix integration delivered via thin `subprocess.run` shim
in `tests/golden/test_*_golden.py` (slice 3).

### D-99-3 — Seed adapter: `langgraph` (over anthropic_agents)

Anthropic Agents had R94 block-content special rendering (Replay UI slice 3). Tempting
to seed there. **Rejected**: anthropic_agents has higher per-round variance (block
shape evolves with SDK), making golden fixtures brittle. langgraph has the lowest
per-round variance and the longest zero-regression streak. Anthropic Agents seed
deferred to v0.10.0+ once the format settles.

## 5. Spike 19 hand-off to R100

**Round shape (R100)**: spike-first implementation. 2-slot pre-budget (per `chronos-spike-authoring` skill).

**File**: `tests/spikes/spike19_golden_trace_invariants.py` (new).

**Three invariants** (run all three in same spike file; spike GREEN = all 3 pass):

1. **Round-trip** — for a synthetic `envelopes.jsonl` (3 envelopes), call
   `replay()` to project a `RunSummary`, then assert byte-equality to the
   pre-committed `expected_run.json`. **Failure mode**: any non-determinism in the
   projector (e.g., dict ordering, time field, UUID re-mint) breaks this.
2. **Projection stability** — assert that `RunSummary` field set is closed under
   addition of new envelope kinds. I.e., adding a new envelope kind must not
   silently introduce new top-level `RunSummary` fields. **Failure mode**: latent
   `**kwargs` spread or `model_dump()` propagating SDK-specific fields to top level.
3. **Sanitiser audit** — assert that a fixture-load step rejects any envelope
   containing `sk-[A-Za-z0-9]{20,}`, `Bearer [A-Za-z0-9._-]+`, or AWS-key shapes.
   Tests at fixture-load (not record) so the invariant is enforced even on
   externally-contributed fixtures.

**Out of scope for R100**: actual `chronos verify-golden` CLI verb (slice 3 / R102),
`langgraph/simple_chat` fixture content (slice 2 / R101), pytest matrix integration
(slice 3 / R102).
