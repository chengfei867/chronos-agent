## Decisions (and why)

- **Demo location = `examples/builtin-minimal/` subdirectory** rather
  than top-level. `examples/` is already a Python package with two
  runnable demos (`linear_pipeline.py`, `router_loop.py`); a per-demo
  subdir keeps each shipped demo self-contained and lets future demos
  drop in beside it without naming collisions.
- **Demo file format ≠ golden-trace contract.** The golden-trace
  `envelopes.jsonl` (under `tests/golden/<adapter>/<scenario>/`) is a
  test-fixture contract consumed by `chronos verify-golden`. Coupling
  quickstart to it would force every quickstart demo to satisfy
  golden-trace's adapter-comparison invariants, which is the wrong
  scope. The quickstart envelope format is a much simpler internal
  shape: one JSONL line per record (`_run` / `node` / `_fork`).
- **`--force` semantics** — drop-and-recreate, not in-place merge.
  Idempotency is what the user wants ("run quickstart twice → same DB").
- **Refuse non-empty DB by default (exit 1, not 0).** The default DB
  path is `./chronos.db` in the user's cwd; silently overwriting their
  real recordings would be a serious footgun.
- **Determinism via fixed epoch + per-step offsets.** No `datetime.now()`
  anywhere in the loader. Tests can assert on IDs without flake.
