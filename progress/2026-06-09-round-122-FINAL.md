R121 ship 加的 `tests/unit/test_cli_doctor.py::test_doctor_render_preserves_extras_in_hint` 函数定义那行 (line 240):

```python
def test_doctor_render_preserves_extras_in_hint(monkeypatch: pytest.MonkeyPatch, tmp_path: Path) -> None:
```

是 105 chars > 88 char ruff line-length, ruff format 要求 wrap 成:

```python
def test_doctor_render_preserves_extras_in_hint(
    monkeypatch: pytest.MonkeyPatch, tmp_path: Path
) -> None:
```

R121 author 单 slot 单 commit ship 时 **没跑 `uv run ruff format --check .`**, 只跑了 pytest GREEN 就 ship。本地 dev tooling 链 (uv run pytest) 对这种 cosmetic drift 不会 fail; 只有 CI `Ruff format check` step 才会 catch。R121 也没 verify 自己 ship 触发的 ci.yml run。
