# Golden trace skeleton fixture (R100 / ADR-028 §4 Slice 1)

This directory pairs an authoring-side envelopes.jsonl with the canonical
projected expected_run.json byte-equal target used by spike 19.

- `envelopes.jsonl` — human-authored 3-envelope skeleton (agent_start, llm,
  agent_end). The R102 ``capture-replay`` driver will consume this shape.
- `expected_run.json` — golden RunSummary projection of the synthetic Run
  reconstructed from those envelopes. Generated by spike 19's
  `project_to_golden`; byte-equality is part of the slice 1 contract.

Do NOT hand-edit `expected_run.json`. Regenerate via:

    uv run --no-sync python tests/spikes/spike19_golden_trace_invariants.py

(if invariants change) or via a future ``scripts/regen_golden.py`` (R102+).
